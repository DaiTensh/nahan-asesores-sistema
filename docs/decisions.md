# Registro de Decisiones

## Propósito

Este archivo registra decisiones relevantes tomadas durante el desarrollo del proyecto.

Su objetivo es evitar que decisiones importantes se pierdan y proporcionar contexto histórico a Claude y al equipo.

---

# Reglas

Cada decisión importante debe registrar:

- Identificador.

- Fecha.

- Contexto.

- Problema.

- Decisión.

- Motivo.

- Alternativas consideradas.

- Impacto.

- Estado.

Las decisiones no deben eliminarse.

Si una decisión cambia, debe registrarse una nueva decisión que indique que reemplaza a la anterior.

---

# Estados

- Propuesta.

- Aprobada.

- Rechazada.

- Reemplazada.

- En revisión.
