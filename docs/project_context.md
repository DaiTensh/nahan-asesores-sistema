# Contexto del Proyecto

## 1. Identificación

**Proyecto:** Sistema web para Nahan Asesores

**Asignaturas:**
- Ingeniería de Software 1
- Ingeniería de Software 2

**Estado:** Desarrollo mediante incrementos.

---

# 2. Objetivo general

El proyecto busca desarrollar un sistema web que permita mejorar la gestión interna de Nahan Asesores, facilitando la administración de clientes, casos, tareas, estados y procesos relacionados con las áreas legales y contables.

---

# 3. Alcance actual

El sistema contempla principalmente:

- Gestión de usuarios.
- Gestión de roles.
- Gestión de clientes.
- Gestión de casos.
- Gestión de tareas.
- Seguimiento de estados.
- Gestión de información legal.
- Gestión de información contable.
- Integración entre procesos.

El alcance puede modificarse de acuerdo con los incrementos y decisiones oficiales del proyecto.

---

# 4. Roles principales

Los roles definidos actualmente incluyen:

- Administrador.
- Usuario legal.
- Usuario contable.

La implementación exacta de permisos debe verificarse en la documentación oficial y el código actual.
