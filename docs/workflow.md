# Flujo de Trabajo del Proyecto

## 1. Propósito

Este documento define el flujo recomendado para desarrollar, revisar y documentar cambios en el proyecto.

---

# 2. Flujo general

```text
Requerimiento
      ↓
Análisis
      ↓
Documentación
      ↓
Diseño
      ↓
Planificación
      ↓
Branch
      ↓
Implementación
      ↓
Pruebas
      ↓
Revisión
      ↓
Documentación
      ↓
Pull Request
      ↓
Revisión humana
      ↓
Merge
